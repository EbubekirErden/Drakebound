# Drakebound 1.1.0

## Changes

- New Combat workspace with ready actions, spells grouped by level, saving throws, slots, resources, conditions, and a separate concentration status card.
- One quick-access search (⌘K) across characters, journal text/tags, companions, owned spells and equipment, and references. Results identify the owner and open the actual saved entry.
- Compact Sheet features, spellbooks, inventory and creature cards; equipment quantities adjust directly from a popup.
- Searchable Conditions category with the Compendium Preview sidebar.
- Per-tab banner sizes, optional per-character tabs, compact rest reviews, clearer export/backup actions, non-blocking notices, and appearance refinements.
- Faster ordered background saving without changing the character archive format.

## Download and install

Requires an Apple silicon Mac running macOS 14 or later.

1. Back up your character data before upgrading.
2. Download `Drakebound-v1.1.0-macOS-arm64.zip` and verify it with `SHA256SUMS.txt` if desired.
3. Quit Drakebound, extract the ZIP, and replace Drakebound.app in Applications.
4. Open the new app. Existing characters and imported references are retained.

This build is **ad-hoc signed** and is **not Developer ID signed or notarized**. macOS may require explicit approval to open a downloaded app. Intel Macs are not supported by this build.

## Scope

Turn/action-economy tracking is deferred. Condition tracking supports typed rolls and tracked stats; target-dependent effects still require table decisions. Included SRD content is licensed under CC BY 4.0 with attribution in Help; the application code has no declared open-source license.
