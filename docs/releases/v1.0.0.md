# Drakebound v1.0.0

Native offline character companion for Apple silicon Macs running macOS 14 or later.

## What's included

- Ready-to-use offline SRD library: 339 spells, 12 core classes with their SRD subclasses, 9 species, 4 backgrounds, 17 feats, equipment/magic-item variants, and creatures. No import is required to start.
- Guided first launch with creation, additive character import, an optional demo, and protected recovery for unreadable archives.
- Guided creation and level-up, searchable compendium and custom editors, resizable reference panels, and consistent page controls.
- Journal quick capture, tags, pinned notes and reordering; equipment reordering within containers.
- Light, Dark and System appearance, refreshed action cards, and explicit note editing.

Existing characters, portraits, imported references and custom content are retained. Back up the local save folder before upgrading. Bundled records load from app resources; unchanged copies are not duplicated into your local archive.

## Download and install

1. Download `Drakebound-v1.0.0-macOS-arm64.zip` and optionally verify it with `SHA256SUMS.txt`.
2. Extract the ZIP and drag `Drakebound.app` into Applications.
3. Open Drakebound. Existing users return to their characters; new users see Welcome.

This build is **ad-hoc signed**, not Developer ID signed or notarized. macOS may require explicit approval for a downloaded app. Follow [Apple's instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac). Intel Macs and macOS versions before 14 are not supported by this build.

## Content and scope

The bundled rules are copyrighted content licensed for reuse under **CC BY 4.0**. Full attribution, license text, adaptation/provenance details and the unmodified official SRD 5.2.1 PDF are included under Help and in the app resources. The structured reference conversion uses Open5e SRD 5.2 metadata, with spell/class/origin/feat descriptions from the 5.2.1 transcription. It is not a complete database of every published book or complete rules automation. The application code has no declared open-source license.

- Compendium, progression and creation regression harnesses.
- Isolated native first-launch, creation/cancel/commit, demo, import, existing-character preservation and recovery checks; light/dark views rendered.
- Successful optimized arm64 build, strict signature verification, resource checksum checks and archive payload inspection.
- Live character, compendium and activity hashes verified unchanged during tests. No user saves or private imports are included in the download.
